# Frontend_Phase1_Capstone, Book Search & Favorites App
 Description

This project is a simple web application that allows users to search for books using the Open Library API
 and save favorite books for later viewing.
It demonstrates how to use HTML, CSS, and JavaScript to fetch API data, manage UI updates, and store data locally using localStorage.

# Features

✅ Search for books by title
✅ Display book cover, title, and author
✅ Add or remove books from your Favorites list
✅ Favorites are saved in localStorage (they remain after page reload)
✅ Responsive and user-friendly design

## How It Works

Type a book name into the search box.

Click Search — the app fetches results from the Open Library API.

Each result shows the book’s title, author, and cover.

Click Add to Favorites to save a book, or Remove to delete it from favorites.

Your favorites appear in the “Your Favorites ❤️” section below the search results.

# Technologies Used

HTML5 — structure and layout

Tailwinf css — styling and responsive design

JavaScript (Vanilla JS) — logic and API handling

Open Library API — data source for books
